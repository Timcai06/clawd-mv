# clawd-mv

A code-rendered music video: Clawd writing code in an editor, set to an original Suno song.
Personal, non-commercial.

Built on [mexicat/pdoom-video](https://github.com/mexicat/pdoom-video) (MIT, see `LICENSE`; upstream commit in
`reference/pdoom/UPSTREAM_COMMIT`). The upstream README, scenes and treatment are kept in `reference/pdoom/`
as examples. The reference song there belongs to its authors and is not committed.

- Plan and status: `docs/PLAN.md`
- Story, song, visuals: `docs/TREATMENT.md`
- Engine and scene API: `docs/ENGINE.md`
- Agent conventions: `CLAUDE.md`

```sh
cd app && bun install && bunx vite   # http://localhost:5173
```
