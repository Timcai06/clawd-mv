## Clawd 动作库（初版，编号供分镜引用）
Clawd 是 16×5 的像素精灵（`reference/clawd/clawd.json`）。所有动作都在这个网格上完成，不加细节、不改比例。只能改变像素的位置（移动、上下弹跳），或者改变眼睛和手臂那几个像素。

| 编号 | 动作 | 像素上怎么做 |
|---|---|---|
| A1 | 睡 | 眼睛那两格填成身体色（闭眼），整体每 2 拍下沉 1 像素（呼吸） |
| A2 | 醒 | 先睁一只眼，再睁另一只 |
| A3 | 待机 | 每拍弹一下（上移 1 像素再落下） |
| A4 | 打字 | 四条腿轮流抬起，每 1/8 拍换一条；手臂一上一下 |
| A5 | 横着走 | 整体水平移动，腿两两交替 |
| A6 | 跳 | 在锚点上跳起，下一个强拍落地；落地那一帧身体压扁 1 行 |
| A7 | 举手 | 两侧手臂那两格上移一行（挡雨，或欢呼） |
| A8 | 慌 | 水平抖动 ±1 像素，频率 1/16 拍 |
| A9 | 数数 | 腿一条条抬起（1、2、3、4），抬完再从头数 |
| A10 | 剪 | 一侧手臂伸长若干像素，再收回 |
| A11 | 下沉 | 缓慢往下移，眼睛朝下（眼睛像素下移一行） |
| A12 | 庆祝 | 连跳，每拍一次，手臂举起 |
| A13 | 挥手 | 一侧手臂上下动 |

## 需要的通用组件（给阶段 5）
这是从分镜里数出来的「零件清单」，也是给 Codex 拆任务的依据：

- Clawd 精灵和动作库 A1–A13（C 做）
- 编辑器：标签页、行号、代码（语法高亮）、光标、打字效果（逐字出现，跟随拍点或歌词）
- 文件树（逐层展开）
- 通知弹窗
- 日历网格（可以多出或删除一格）
- 待办清单（打勾）
- 终端（输入命令、输出一行行出现）
- 测试列表（每项有红、绿两种状态，可以碎、可以抽搐）
- 报错雨（文字粒子，确定性）
- git log / 提交哈希（弹出、堆叠）
- 调用栈（层层下沉）
- PR 页面、评审头像、合并动画（分支线）
- 多设备屏幕框
- 歌词排版层（沿用上游的逐词同步）
