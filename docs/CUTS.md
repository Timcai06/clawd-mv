## 规则
1. **R1 切点在句间**：`snap: "cut"` = 句首词起点 + 50 ms 之前（含）的最后一拍（pdoom `cut()`，容差照 dense）。改 6 个切点（见下表「新时间」）。例外只留 C1（ping 本身就是下一场的开场冲击）。
2. **R2 跨切点的词**：下一场只把这个词在上一场的**屏幕版面**里唱完，不重排整句；上一场把这句的版面写成可导出的纯函数，下一场调用同一个函数（照 pdoom `room-shrooms.ts`）。尾巴 ≤ 0.1 s 的词在上一场唱完即可，下一场不画这一句。
3. **R3 交接原语**：每个切点一个屏幕空间的几何原语（点 / 线 / 矩形 / 点集），已经算上两场各自的镜头（`kit/lens.ts` 的推拉、3D 相机）。上一场导出 `exitPrim(t)`，下一场导出 `entryPrim(t)`，注册进 `app/tests/handoff.test.ts`：切点前一帧和后一帧的原语误差 ≤ 2 px、尺寸误差 ≤ 2%。
4. **R4 切点前**：上一场最后 1 拍收成原语（加速：`ease.inCubic` 或细分到 16 分音符），最后 0.1 s 原语本身定住；下一场从原语展开，镜头运动方向接上。
5. 不改场景的画面主体（构图、配色、歌词载体留给 ②）；改的只有：切点、每场开头 1 拍和结尾 1 拍、跨切点的那句歌词的版面。
