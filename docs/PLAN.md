## ⏳ 阶段 2：Suno 生成（T 操作，C 给数据）
1. 用 Custom 模式，贴入歌词和风格描述，v6 和 v6-wild 都试，先生成 10–20 版。
2. T 挑 3 个候选下载到 `audio/candidates/`（占 3 次下载额度，每月 20 次）。
3. C 逐个测：BPM 稳定性、段落边界是否对上结构表、时长、Whisper 转写和歌词的吻合率。
4. T 结合听感和数据定稿，不满意的段落用分段替换修，然后下载最终版。
- **完成标准**：时长 1:50–2:10、速度稳定、歌词吻合率 ≥ 90%、T 满意听感。
