# 事件表：每句歌词让画面发生什么（阶段 9 ③，2026-10-03）

T 2026-10-03 看完 v6 整片后指出：有几场「只是单纯的字幕在那里有一点动效」。核实（逐句 4 帧抽样，见 CONTEXT「③ 事件驱动」）：S17、S13、S12、S08、S06、S05 有多句在唱的过程中画面除了字几乎不变。pdoom 的做法是**词是触发器**：每句至少一个关键词让世界发生一件和词义对应的事，镜头按词或音节换机位（`room.ts` `buildShots` 一词一机位；`bureau.ts` `camB` 一音节一个关键帧、`caretX` 镜头跟着书写头）。

规则（从这一版起每场都按这个写）：
1. 每句列出关键词 → 世界里发生的事（≥ 2 件，落在词首或拍上）→ 镜头怎么变（机位关键帧在词首用 outExpo 约 0.2 s 猛切，之后基本静止）。
2. 没有事件的句子不能只写字。
3. Clawd 是演员：歌词里的动作尽量由它做。
4. 镜头在画布里做（矢量，`applyCam2`），不用 Lens 放大位图，避免字发虚。

T 定先做 S17（中段）和 S05 两场样板。
