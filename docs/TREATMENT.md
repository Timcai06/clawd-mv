## 音乐参考：pdoom（Claude-Pop 版，Suno 制作）
原曲在 `reference/pdoom/audio/pdoom.mp3`，只供本地参考。下面是上游分析得出的**客观数据**（`reference/pdoom/data/audio.json`，以及上游 `analysis/analyze.py` 的注释）：

- 132 BPM，4/4 拍，全长 156.7 秒，速度恒定。
- 和弦：主歌是 Eb–Bb–Cm–Ab（Eb 大调的 I–V–vi–IV），每个和弦 2 小节。
- 编曲上的「招数」，这些是可以写进风格描述和歌词结构的东西：
  - 主歌开头没有鼓，第 7 小节鼓才进来。
  - 预副歌只有 3 小节。
  - 每次副歌前有一个约 3 拍的**弱起**（「I'm upping my P-」），同时贝斯停下来，然后主题词重重落在下一小节的第一拍（「DOOM」）。
  - 第三段预副歌是 breakdown：鼓和贝斯都退出。
  - 第三遍副歌做成安静版：轻鼓、没有贝斯。
  - 最后一遍副歌结尾有一个停顿小节，接着是全乐队的尾奏。
- 段落（小节数）：前奏 1 / 主歌 8 / 预副歌 3 / 副歌 8 / 过门 1 / 主歌 8 / 预副歌 3 / 副歌 9 / 主歌 8 / 预副歌 3 / 副歌（安静版）8 / 桥段 8 / 副歌 9 / 尾奏 约 7 + 渐弱。

- Tim 的关键词（2026-09-30）：**欢快、电子**（upbeat, electronic）。

## 结构提案：约 2 分钟（132 BPM，1 小节 ≈ 1.82 秒，66 小节 ≈ 120 秒）
