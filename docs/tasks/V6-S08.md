先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C7、C8）、`docs/reference/pdoom-transitions-lyrics.md` 第 2.3 节（hook 四次）和 R7。设计：C。实现：Codex（推理强度 xhigh），严格按本规格。整场重写（v5 方法）。

## 设计意图
commit 就是「把墨压到纸上」。这一场是一台活字印刷机：一张很大的纸平铺在印床上，被一盏低角度的灯扫着。每唱一个词，一块这个词的实体铅字从镜头这边砸到纸上，抬起来，纸上留下这个词的印痕——印痕是压进纸里的凹字（灯一扫就看得见深度），沾了墨。COMMIT 是第 1 级：干净、单个、满宽。唱到 MIT，整块 COMMIT 砸下，clay 墨从字块底下炸开铺满整张纸，只有凹进去的 COMMIT 留着纸色。然后括号一对对飞来扣住它；Clawd 跳上纸，四条腿像琴槌一样把「TAP-TAP-TAPPING」一个字母一个字母敲进纸里；纸被走纸机卷上去；第二次 COMMIT 叠印在第一次上，套印错开。最后镜头拉远：这张纸原来是 Clawd 那台笔记本的屏幕——「on my machine」。唱到 machine，屏幕像老 CRT 一样关掉，收成一条横线。

## 1. 数学世界 `parts/s08-world.ts`
- **纸**：印床上的一大张纸，xz 平面 y = 0，`PAGE = { w: 48, h: 27 }`（世界单位，16:9），中心在原点；在 L3 之后会沿 −z 方向「走纸」（第 5 节）。纸用位移网格（`PlaneGeometry` 768 × 432 段）+ `engraveMaterial`，凹字用 **高度贴图**（`bumpMap` 或顶点位移 + 解析法线，取舍写报告）：`depthMap(x, z, t)` = 所有已经压下的字块的字形遮罩 × 压深 0.06。遮罩和墨色都画在两张 Canvas 贴图里（`PRINT`：墨色，`DEBOSS`：深度），**每帧从 t 重新画**（所有 `t ≥ 压下时刻` 的印痕），保证确定性；贴图分辨率 4096 × 2304（`SCALE` 无关，纸很大）。
- **字块**：每个唱词一个 `SolidText`（`kit/solidtype.ts`），`axes` = 该词唱完时的 `Voice.form().axes`（重读词 wght 900），`depth = 0.5·capH`；印面朝 −y（字块倒过来压在纸上——印出来的字是正的：字块用镜像几何，或者把字块绕 x 轴翻转 180° 放在纸上方，让「从上往下看纸」时字是正的，取舍写报告）。
- **一次「压印」** `press(word, tp, pos, rot, capH)`：字块在 `tp − 0.14 s` 出现在纸上方 `y = 3·capH`（离镜头很近），`ease.inQuad` 落下，`tp` 触纸；触纸瞬间印痕写入 `PRINT`/`DEBOSS`，纸面在字块周围下陷 0.02（`springStep`，0.2 s）；字块在 `tp + 0.10 s` 起 `ease.outCubic` 抬起飞回镜头方向，`tp + 0.35 s` 后不画。墨色：普通词 = ink；重读词 = clay。
- **光**：一盏方向光，极低角度（仰角 14°，方位从左前方 `(−0.8, 0.27, 0.55)`），使凹字的一侧亮边、一侧影子都很清楚；投影（字块投在纸上的影子，落下时影子先于字块到达）。环境光 0.1。纸是 paper 底 + ink 刻线（受光少的地方刻线密）；clay 墨区域里刻线换成 paper 色画在 clay 上（材质 `paper` 参数在 clay 区域取 clay——用 `PRINT` 贴图作为 `paper` 色的来源：在 `engraveMaterial` 里把 `paper` 换成采样 `PRINT` 的颜色，C 在 V6-K2 合并后加 `paperMap` 选项）。
- **Clawd**（L3、L5）：`kit/clawd3d.ts` 体素 Clawd，1 体素 = 0.5。
- **笔记本**（L5）：一台体素风格的笔记本（底座 + 屏幕两块长方体，`engraveMaterial`），屏幕的显示面**就是这张纸**（纸是屏幕的内容：在 L5 把纸放到屏幕平面里，镜头拉远时看到纸被屏幕边框框住）。屏幕尺寸 = PAGE 的 1/1（纸就是屏幕，世界不缩放；笔记本本体按这个尺寸造：底座 50 × 1.6 × 30，铰链在纸的下边缘 z = +13.5，屏幕后仰 105°）。

## 2. 编排（镜头 + 字，按段）
**镜头通则**：`Cam` 分段函数；段内用 `orbitCam`；「快切」在世界内完成（同一个世界，下一帧镜头直接跳到新机位——照 pdoom room 的逐拍重构图），每次快切都在词首或拍上。

### A. L1「I need one more」（`T.i1` → `commit`.start 26.48）——四次满屏压印
- 第一帧（C7 接）：镜头贴在 **I 字块的印面**上（印面是 clay，刻线角度 0.6、间距 5 px，和 S07 Enter 键面一致），印面铺满画面。`T.i1` 起 0.15 s，镜头 `ease.outExpo` 后拉（I 字块此时刚触纸、正在抬起），看到纸上 clay 的 I 印痕（I 是本句第一个词，重读，clay）。
- `need`、`one`、`more`：每个词在它的 start 压印；每次压印镜头快切到一个新机位：印痕在纸上的位置依次是 `(−14, −6)`、`(9, −8)`、`(−6, 5)`（纸面坐标），每个词的 capH 让它在镜头里大写高 ≈ 画面高度的 48%（满屏级），每个印痕的旋转（绕 y）分别 −0.05、0.04、−0.02。镜头机位：俯角 1.15（从水平量），正对该印痕，距离解出来使字宽 ≈ 画面宽 80%。
- 每次压印：2 帧反色（`post.invert`，照 pdoom hook），镜头震 7 px（`noise1`），按住的词以每秒 3.5% 的速度推近。
- 层级：每个词就是主导元素；不放任何其它字。

### B. COM-MIT（26.48 → `T.brk`）——第 1 级冲击
- `commit` 第 1 音节（26.48）：COMMIT 字块（满宽：capH 让它在镜头里宽 = 画面宽 92%，`wdth` 用 `Voice` 的值，wght 900）出现在纸心上方高处，**慢**（`ease.inQuad`）降落，镜头同时后拉到俯角 1.3、看到整个纸心——这是蓄力（R4：最后 0.1 s 镜头静止）。
- `T.mit1`（26.94）：砸下。印痕 = 凹字（`DEBOSS` 写入），**墨**：clay 从字块底下向外炸开铺满整张纸（`PRINT` 里画一个以纸心为中心、半径 `r(t) = R·ease.outExpo((t−T.mit1)/0.3)` 的 clay 圆，边缘用 `fbm` 扰动 ±4%），凹进去的 COMMIT 字面不着墨（保持 paper 色）。镜头震 10 px，2 帧反色，`zoom` 冲 4%，`bloom` 不加（不靠发光）。
- 哈希：`a1f3c9e`（Plex Mono，标注级，ink 色）在 MIT + 1 拍时印在 COMMIT 右下角外（纸面上，lie 模式 `pathtext`，打字式逐字出现，0.5 拍）。
- 之后到 `T.brk`：镜头绕 y 慢转 0.12 rad，低角度光把 COMMIT 凹字的立体感扫出来。

### C. L2「Every bracket’s gonna fit」（`T.brk` → `T.tap1`）——括号扣住
- 歌词 `Every bracket’s gonna`：小压印（歌词级：大写高投影 70–90 px），沿 COMMIT 下方一条直线依次压印（像排一行铅字），ink 墨（压在 clay 上，所以是 ink 印痕），每个字母按 `letterTimes` 依次压（这一句逐字母压印：每个字母是自己的小字块，落下时间 0.08 s）。
- 括号：`( )`、`{ }`、`[ ]` 三对，各是 `SolidText`（Archivo wght 900，capH = COMMIT 的 1.15 倍），从画面外沿弧线飞来（各自从左右两侧对称进场），第 k 对在 `T.brk + k 拍`（k = 0,1,2）落位并压印到 COMMIT 两侧（三对一层套一层：`[ ]` 最外，`( )` 最内）。
- `fit`（30.37）：最外一对在 `fit`.start 精确合拢——落位误差为 0（「严丝合缝」），合拢瞬间整张纸向下顿 0.03（`springStep`），镜头震 6 px。
- 镜头：`T.brk` 起拉远到俯角 1.45（近乎正俯视），使三对括号 + COMMIT 的整体包围盒 = 画面宽 88%；`fit` 后保持。

### D. L3「Tap-tap-tapping, never quit」（`T.tap1` → `T.i2`）——Clawd 当琴槌
- `T.tap1`：Clawd 从画面右侧跳上纸（抛物线，0.5 拍），落在 COMMIT 下方。
- `Tap-tap-tapping,`（31.21–33.46，2.25 s，13 个字母含连字符）：用 `letterTimes`（这个词长，按规则 0.8 / 0.7——**这里改为 spread = 1.0、maxSpan = 2.25**，让 13 个字母铺满整个词：`letterTimes(word, { spread: 1, maxSpan: 2.25 })`），每个字母由 Clawd 的一条腿敲进纸里：Clawd 四条腿按 1-3-2-4 的顺序轮流抬起、砸下（每次 0.08 s 抬、0.05 s 砸），砸下的腿正下方印出这个字母（小凹字，ink 墨，大写高投影 70–90 px），Clawd 每敲一个字母向右挪一个字宽。连字符也敲。
- 镜头（三个快切，挂在三个镜头锚点上）：`T.tap1` 正面低机位（俯角 0.25，看 Clawd 正面）；`T.tap2` 侧面（yaw +1.2）；`T.tapping` 正俯视（看四条腿像琴槌起落，字一个个出现）。
- `never quit`（33.46–34.40）+ `T.quit`：**走纸**：整张纸沿 −z 方向滚动（纸面坐标整体平移，速度从 0 到 6 单位 / 拍，`ease.inCubic`，`T.quit` 起），印过的东西（COMMIT、括号、TAP 行）一起往画面上方远处滚走，像倒流的瀑布；`never`、`quit` 两个词在纸的新区域压印（歌词级，`quit` clay）。Clawd 站在纸上被纸带着走，跳一下回到画面中间。

### E. L4 第二次 COMMIT（`T.i2` → `T.works`）
- `I need one more` 同 A 段（四次满屏压印，但位置换成 `(12, 4)`、`(−10, 7)`、`(4, −9)`、`(−15, 2)`，旋转反号）。
- COM-MIT（`T.mit2`）：同 B 段，但这次是**叠印**。纸在 D 段已经把第一次 COMMIT 卷走了，所以 `T.i2 − 0.5 拍` 起纸**倒卷**回来（−6 单位 / 拍 → 0），`T.mit2` 时第一次 COMMIT 回到纸心；第二次 COMMIT 砸在它上面，**套印错开**（向右下偏移 (0.35, 0.2)·capH，旋转 −0.015）：两层凹字交叠，墨区是 clay，交叠处的凹字更深。哈希变成两行（`a1f3c9e` / `5d2b70f`）。
- 冲击和第一次相同（第 1 级的两次之间不升级；升级在 S13、S17）。

### F. L5「’Cause it works on my machine」（`T.works` 起）——这是我的机器
- `’Cause it works`：歌词级压印（ink），沿纸下方一行。`works`（39.48–40.27 长音）字宽随 `Voice` 拉宽（逐字母压印后，整词的凹字宽度随轴变化——印痕宽度不可变；做法：works 的字块在纸上方悬停到唱完再压下，悬停期间宽度跟着拉；取舍写报告）。
- `T.works`：镜头开始**拉远**（`ease.inOutCubic`，到 `T.machine`）：纸被笔记本的屏幕边框框住，再拉远看到整台笔记本放在 ink 的桌面上，Clawd 站在键盘区，抬起一只手臂（竖大拇指——手臂像素抬 1 格）。笔记本屏幕里（就是这张纸）同时出现一块「本地预览」：一个 7 × 5 的月历印痕，第 32 格被划掉，只剩 31 格（在 `on`(41.16) 压印）。
- `on my`：`pathtext` stand 模式，站在笔记本前的桌面上（歌词级）；`my`(41.48–42.84) 长音：字宽拉到 125。
- `machine`（42.84）：屏幕右下角一个像素闪红一次（`fail` 色，2 帧，伏笔），然后——
- **退场（C8）**：`T.machine` → `T.end`：屏幕内容像 CRT 关机：先竖直方向压扁成一条横线（`scaleY` → 0，`ease.inCubic`，0.25 s），横线再横向拉满画面宽，同时镜头推近使这条线在屏幕 y = 540（`base08`）；切点前一帧画面上只有这条 paper 色细线（宽 2 px）+ 跨切点的 `machine`。`exitPrim` = `{ kind: 'line', x0: 0, y0: 540, x1: 1920, y1: 540, w: 2 }`。
- `machine` 的 carry（C8）：`machine` 字块在 `T.machine` 时不压印，而是悬在纸上方；最后半拍从 3D 姿态 `lerpAffines` 到 `CarrySpec { text: 'machine', x: 96, y: 470, size: 110, axes: 当时的 Voice 轴, color: 'paper' }`，S09 接手。

## 4. 可测验收
- 每次压印的触纸时刻 = 该词（或字母）的时刻（< 1 帧）；`T.mit1`、`T.mit2` 触纸 = commit 第 2 音节。
- A 段每个词的字块投影宽 ≥ 画面宽 70%（触纸那一帧）。
- B 段：MIT 后 0.3 s，`PRINT` 贴图里 clay 覆盖纸面 ≥ 95%（凹字除外）。
- C 段：`fit` 时最外一对括号的落位误差 = 0（位置函数在 `fit`.start 精确到达目标）。
- D 段：TAP 行 13 个字母的出现时刻严格递增，且等于 Clawd 对应腿砸下的时刻。
- C7、C8 误差 ≤ 2 px；`machine` carry 仿射和 S09 第一帧使用的逐项相等。
- 性能：每帧平均 < 25 ms（纸的贴图每帧重画是最贵的部分：只重画变化的区域，或者把已完成的印痕缓存到一张底图里——缓存必须只依赖 t 之前固定的事件集合，seek 后结果相同，测试）。
- 静帧（每段 2–3 张）：24.74、24.90、25.00、25.50、26.10、26.70、26.96、27.30、28.60、29.70、30.38、31.40、32.20、32.70、34.00、35.30、37.69、38.00、39.80、41.30、42.86、43.10、43.30 s；短片 24.2–44.0 s。
