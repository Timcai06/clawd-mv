# V6-S02：PING——四块砸下来的字（5.611 → 6.512 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C1、C2）。设计：C。实现：Codex，严格按本规格。

## 设计意图
0.9 秒，一记通知音。I 就是上一场的光标（还在发光）；P、N、G 三块有厚度的字从镜头这边砸到海报上，按「ping」的字母时刻一块接一块落地。I 是一盏 clay 灯，所以每块字落地时，它的影子都从 I 向外甩出去。海报左边是墨、右边是纸（分割线 x = 624），字跨在分割线上。最后一拍字一块块倒下掉出画面，只剩分割线——它就是下一场那张纸的左边缘。

## 时间
`T.ping` = 5.611（场景起点）、`T.issue` = S03-1 起点（6.512）。`ping` 5.56–5.87；字母时刻用 `letterTimes(ping)`：P、I、N、G 依次。`on`(5.87) `my`(6.02) `screen`(6.12–6.72，尾巴跨切点 0.21 s)。

## 1. 数学世界 `parts/s02-world.ts`
- **海报平面** z = 0，覆盖全屏且更大；镜头正对它（相机在 +z，看向 −z）。分割：屏幕 x < 624 的部分是 ink，> 624 是 paper（在世界里换算成海报上的一条竖线，镜头不动时它就是屏幕上的 x = 624）。
- **PING 版面**：`varRun('PING', size, { wdth, wght: 900 })`，`wdth` 用 `fitVar` 解出，使整词墨框 = `PING_BOX = { x: −70, y: 170, w: 2060, h: 625 }`（屏幕，镜头静止、字落地时）。导出 `iStemRect()`：I 的墨框（屏幕 px）——这就是 C1 的 `I_STEM`。
- **字的实体**：P、N、G 三个字母各用 `vartype` 的轮廓建 `THREE.ExtrudeGeometry`（厚度 = 大写高的 0.12，倒角 0.012，倒角分段 2），落地后背面贴在海报上。I 不是字形，是一块 clay 自发光的长方体，尺寸就是 I 的墨框，厚度同其它字。
- **光**：两盏。① I 自身是点光源（位置在 I 的中心、z = 厚度 + 0.1），强度在每块字落地时脉冲（`1 + 2.5 · pulse(t, 落地时刻, 0.12)`）；② 左上方的低角度主光（方向 `normalize(−0.6, 0.7, 0.4)`），强度 0.55。两盏都投影（three.js 阴影贴图，点光源用立方体阴影，分辨率按 `SCALE`）。
- **刻线**：字的正面、侧面和海报都用同一个刻线着色器：先算两盏灯的辐照度，再 `engraveTone` 成刻线覆盖率；字在 ink 半边的部分线是 paper 色，在 paper 半边的部分线是 ink 色（字跨分割线时颜色在分割线处翻转——在着色器里按屏幕 x 判断）。海报上被 I 照亮的区域是一圈从 I 向外衰减的亮区，字的影子把它切成放射状的暗楔。

## 2. 动作和镜头
- I：第一帧就在 `iStemRect()`（= S01 最后一帧的光标），亮度接 S01 的 flare，0.3 拍内回落到 1。
- P、N、G：各自在自己的字母时刻从 `z = +2.4 × 大写高`（离镜头很近，画面里很大，出画）落到 z = 0，`ease.outExpo`，0.09 s；落地瞬间：该字压扁 6%（z 方向）再弹回（`springStep`），镜头震 6 px（`noise1`），海报上以落点为中心一圈涟漪（刻线间距向外推开 1.5 倍再回来，0.25 s）。注意 P 的字母时刻可能早于 `T.ping`（5.56 < 5.611）：早于场景起点的字母在第一帧已经落地 1 帧（不要补画它下落的过程）。
- 镜头：正对，`fov 34`；从 `T.ping` 起总共只做一件事——随三次落地各向内冲 1.5%（叠加、各自 `exp` 衰减 0.08 s），最后 0.1 s 定住。

## 3. 歌词
- **ping** = 这四块字本身（巨字，主导元素）。
- **「Nine o’clock, a」**：用 S01 导出的 `line01Affines()` 原样画在原处（paper 色，在 ink 半边；跨到 paper 半边的字母换成 ink 色，按字母中心 x 判断）。
- **「on my screen」**：沿同一条投影基线续排——下一个字母的仿射 = 「a」的仿射沿基线方向平移（词间距 0.32 em），透视缩放按 S01 那条基线的缩放规律外推（S01 导出 `line01Next(i)`：第 i 个后续字母的仿射，用同一个镜头投影同一条地面直线算出来）。字母按 `letterTimes` 出现、白热冷却。
- **`screen` 跨切点（C2）**：`CarrySpec` = 它在上述基线上的仿射（`carryDrift` 在长音期间轻微漂移，d = 0.3）；S03 第一帧接手（见 V6-S03）。

## 4. 退场（C2）
- 最后 1 拍（`T.issue − 1 拍` → `T.issue`）：G、N、P、I 依次（间隔 1/16 拍）以底边为轴向镜头倒下（绕 x 轴转 90°，`ease.inCubic`，0.35 拍），倒下后沿 −y 掉出画面；I 倒下时熄灭成普通的 paper 实体。歌词行不动。
- 切点前一帧：画面只剩海报的墨/纸分割线 + 歌词行。`exitPrim` = `{ kind: 'line', x0: 624, y0: 0, x1: 624, y1: 1080, w: 1 }`。
- `entryPrim(T.ping)` = `{ kind: 'rect', ...iStemRect() }`。

## 6. 可测验收
- 三块字落地的时刻 = 各自的字母时刻（误差 < 1 帧）；落地前不投影。
- 落地后 PING 墨框投影 = `PING_BOX`（误差 ≤ 2%）。
- C1、C2 误差 ≤ 2 px；`screen` 的 carry 仿射和 S03 第一帧使用的逐项相等。
- 静帧：5.62、5.66、5.74、5.82、5.95、6.25、6.40、6.50 s；短片 5.0–7.0 s。
