# V6-S07：键盘浪——逐字母按键，冲进 Enter（20.901 → 24.729 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C6、C7）。设计：C。实现：Codex，严格按本规格。
S07 的世界（v5：键盘浪的高度场阴影，`scenes/s07-keyboard.ts`、`parts/s07-terrain.ts`）**保留不动**。本任务改进场、歌词、退场。

## 设计意图
上一场的笔尖落在哪里，这一场第一颗被按下的键就在哪里，键盘从那一点向外起伏开来。每个唱出的字母按下一颗键：短词一颗键一个词，长音 looking 的七个字母沿一排键依次按下，像真的在打字。唱到 back，Enter 被按下，镜头一头扎进 Enter 发光的键面——键面上的刻线直接变成下一场的整屏 clay。

## 时间
`T.keyboard` = S07-1（20.901）、`T.dive` = S07-2（`looking`）、`T.end` = S08-1（24.729）。第 5 行：`Claws`(21.08–21.48) `on`(21.48) `the`(21.60) `keys`(21.76–22.30) `and`(22.30) `I’m`(22.52) `not`(22.70) `looking`(23.10–24.26) `back`(24.26–24.73)。

## 1. 进场（C6）
- 第一帧：`WORD_KEYS[0]`（「Claws」的键）的顶面中心投影 = `pen06`（671, 809）（误差 ≤ 2 px）。现在的 `handoffIn` 是从 pen06 线性插值到键，改成：镜头在第一帧就解成让这颗键落在 pen06（键盘浪的高度用 `keyHeight` 在该 t 的值）。
- 镜头开场接 S06 俯冲的速度：现有 `cameraAt` 的 `drop`（从高处、过度滚转落下、弹簧落定）保留，但第一帧的 roll = −0.26 − π/12 的组合要和 S06 末帧的 roll 连续（S06 导出的 `exitVelocity` 给出 roll 角速度；S07 第一帧 roll 的变化方向一致，误差 ≤ 10°）。
- 键盘的显现：`T.keyboard` → `T.keyboard + 1 拍`，以 pen06 那颗键为圆心，键帽按距离依次从 y = −0.6 升到浪的高度（每颗键的出现时刻 = 距离 / 9 单位每拍，`ease.outBack`），像水波从笔尖那一点扩散出去。
- `entryPrim(t)` = `{ kind: 'point', x, y, r: 6 }`（第一颗键顶面中心的投影）。

## 2. 歌词：逐字母按键
- 载体换成 `kit/wordplane.ts`：每个词一块 `WordPlane`，平躺在它的键帽顶面上（贴面、随键起伏、随键按下一起下沉），`karaoke(word, t)` 逐字母点亮（cSung = clay 白热 → cDone = ink）。删掉现在的 `Plate` 贴图做法。
- 按键：词的第一个字母时刻，键按下（下沉 0.12，0.06 s，`ease.outQuad`；松开 0.18 s `springStep`），键面变 clay（现有 `keySung`）。
- **looking**（1.16 s 长音）：不放在一颗键上。L-O-O-K-I-N-G 七个字母各占一颗键：从 `WORD_KEYS` 中 `looking` 那颗键开始，沿同一排向右的 7 颗相邻键（在 `TERRAIN_KEYS` 里按 x 排序取），每颗键在它的字母时刻（`letterTimes`）按下，字母是单字母的 `WordPlane`（`letters()` 拆出来）。
- **back**：在 Enter 上（现有）。
- 层级：主导是键盘浪（≥ 30%）；歌词字在键面上投影大写高 50–110 px（在 `T.dive` 之前的近景里测）；标注只留键帽上的字母（键帽标签算物体，不算标注），删掉其它说明文字。

## 3. 光标（R6）
光标就是「正在被按下的那颗键」的 clay 光：键按下时它的 clay 面最亮（`emissive`），0.28 s 冷却。不另画光标块。

## 4. 退场（C7）
- `back`.start（24.26）→ `T.end`：镜头沿 Enter 键面的法线方向俯冲进键面，`ease.inCubic`；Enter 键面 clay 发光，键面上有刻线（角度 0.6 rad、间距 5 逻辑 px 的屏幕空间平行线——让 S08 开场的 clay 刻线场和它完全相同）。
- 到 `T.end − 1/60`：Enter 顶面的四个角投影后都在画面外（余量 ≥ 0），即键面铺满画面。最后 0.1 s 的规则 3 在这里不适用（冲进去的速度保留到切点，S08 第一帧是静止的 clay 场 + 「I」砸下，速度在 S08 由冲击吸收）。
- `exitPrim(t)` = `{ kind: 'rect', x: 0, y: 0, w: 1920, h: 1080 }` 当且仅当键面完全覆盖画面（测试：四角都在画面外）；之前返回键面投影的包围盒。
