## S12
1. **曝光**：按 `V6-common.md` 第 2 节第 3 条。受光的桌面和纸面 tone 0.80–0.92，影子 0.15–0.30。现在整场是中灰。
2. **去掉光斑**：现在扫描光条下有三团大白光斑（三盏点光照在桌面上 + 后期辉光），这是被禁止的「加发光」。改：光条是**线光源**：照度 = `I · max(0, N·L) / (1 + (d/0.6)²)`，`d` 是到光条线段的最近距离，`L` 指向线段上的最近点（不用三盏点光；在 `engraveMaterial` 外再加一个自定义的线光照项——如果 `engraveMaterial` 不支持自定义光项，把这个照度当作附加的 `emissive` 不行，因为它要参与刻线：请在报告里说明你的做法，必要时提出要 C 在 kit 里加的接口，先用 `onBeforeCompile` 在本场的材质副本上实现）。本场后期 `bloom: 0`。光条本身是细长的 clay 实体（自发光），不画光晕。
   - 像素统计：光条扫过时（60.30、60.70 s），画面里亮度 > 0.97 的像素只能出现在光条本体的投影范围内（允许 4 px 外扩）。
3. **字不叠**：`Clear the cache`（刮板刷出）在 `count`.start 之前随刮板一起被推出画面（刮板扫完后继续前进，把刷出的字一起推走——字是刷在刮板后面的桌面上，刮板回扫时擦掉它：选一种，写进取舍清单）；`and count to` 站在数字行**前方**、和数字行不重叠。测试：65.50、66.10、66.70、67.00 s，不同歌词行的投影墨框两两不相交，歌词行和数字行的投影墨框不相交。
4. **退场颜色**：C12 的切点前一帧，`DIAG13` 左边的区域必须是 clay（11 的第二笔是 clay 实色，不刻线、不受光影响变白：它的材质是纯自发光 clay，`emissiveK` 1，底色 0）。像素统计：67.21 s 帧里，DIAG13 左侧离线 ≥ 20 px 的像素，和 clay 的 sRGB 色差（各通道绝对差的最大值）≤ 12/255 的比例 ≥ 95%。
