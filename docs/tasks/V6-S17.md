## 设计意图
第 3 级是世界尺度。所有机器——成百上千台设备——是一群可以排队形的像素：每台设备是一个像素，亮屏 = 墨，暗屏 = 纸。上一场第 19 块骨牌的绿面，就是第一台设备的屏幕。镜头从这一块屏幕往后拉，「I need one last」一个词一块屏；唱到 MIT，镜头已经拉到最远，**整个设备群同时亮成一个巨大的 COMMIT**——然后全片唯一的一次完全静止（一拍）。接着队形一路变：PR 的两行 diff（`- d <= days` / `+ d < days`），评审的一个大勾，两行合并成一行（光标是拉链头），「free」时所有设备散开飞起，最后排成那只 16×5 的巨型 Clawd。每一块屏上都写着 every machine。

## 1. 数学世界：设备群 `parts/s17-swarm.ts`（新建，和 `s17-world.ts` 共用设备几何）
- **设备**：沿用 `s17-world.ts` 的设备板（实体 + 发光屏 + 刻线）。数量 `N = 1400`（实例化渲染，`InstancedMesh`，每帧更新矩阵和屏幕亮度属性）。
- **队形** `formation(name)`：一组 `N` 个目标位置（世界坐标，都在平面 z = 0 或其附近）+ 每台的屏幕亮度（1 = 亮 clay / 0 = 暗）。队形用字形光栅化生成：把一段文字用 `varRun` 画到一张小画布上（每个画布像素 = 一台设备），取覆盖率 > 0.5 的像素为「亮」；多余的设备放在队形周围当「暗」像素（排成整齐的网格背景）。队形：
  1. `SCREEN`：只有第 1 台设备在画面里（其余在它身后的网格里，暗）。
  2. `COMMIT`：文字 `COMMIT`，光栅 96 × 20（设备间距 0.6）。
  3. `DIFF`：两行 `- d <= days` / `+ d < days`，光栅 90 × 26；第一行亮屏是 `fail` 色，第二行亮屏是 `pass` 色（diff 的删除 / 新增，语义色允许）。
  4. `CHECK`：一个大 ✓（`pass` 色），光栅 40 × 30。
  5. `TWO_ROWS` → `ONE_ROW`：两行设备（各 40 台，上一行是分支、下一行是 main）→ 拉链式合成一行 80 台。
  6. `SCATTER`：所有设备飞散到一个大球壳上（半径 30，位置按 `hash` 固定）。
  7. `CLAWD`：v5 的设备墙（16×5 的 Clawd）+ 雾里的远处 Clawd 群（`s17-world.ts` 现有的 `ECHOES`）——这是最终队形，和现在的画面完全一致。
- **队形之间的过渡**：每台设备从旧位置飞到新位置，路径 = 一条带高度的弧线（中点向 +z 抬 `2 + 3·hash(i)`），时长 0.5–0.9 拍（`hash` 固定），出发时刻按它离画面中心的距离错开（外圈先飞），`ease.inOutCubic`；屏幕亮度在到达时切换（0.08 s）。设备 i 在两个队形里的配对：按目标位置排序后一一对应（最小化总距离的近似：两边都按 (x, y) 排序配对），配对表在 init 里算好。
- **光**：一盏方向光从左上前方，设备的实体部分 `engraveMaterial`；屏幕是自发光（亮屏 clay / pass / fail；暗屏 ink）。雾按深度（现有）。

## 2. 编排
### A.「I need one last commit」（`T.i` → `T.pull`）——第 3 级
- 进场（C16）：第一帧，第 1 台设备的屏幕投影 = `domino16 = {1602, 580, 247, 430}`（误差 ≤ 2 px），屏幕亮着 pass 绿（接上一场骨牌的绿面），0.3 拍内变成 clay。
- `I`、`need`、`one`、`last`：每个词在词首出现在一台新设备的屏幕上（`WordPlane` 贴在屏幕上，歌词级之上：占满那块屏幕宽的 80%），镜头每个词往后拉一级（距离 ×2.2，`ease.outExpo` 0.25 s，四级），每拉一级画面里能看到的设备多一圈，那些设备的屏幕上都闪一下刚才那个词（小号）。
- `commit` 第 1 音节（115.44）：所有设备开始飞向 `COMMIT` 队形（过渡时长压缩到正好在 `T.hit` 全部到位），镜头拉到最远（整个 COMMIT 队形宽 = 画面宽 90%）。
- `T.hit`（MIT）：**全部屏幕同时点亮**成 COMMIT（亮度 0 → 1 在 2 帧内），冲击：镜头震 **24 px**、`zoom` 冲 6%、4 帧反色——这是全片最大的一次冲击（S08 7/10，S13 13/18，S17 24）。
- **静止**：`T.hit + 0.25 s` 起的**一拍**里，一切静止：镜头不动、设备不动、不震、不闪（`exitEnvelope().still` 的逻辑用在这里），画面上只有这个 COMMIT。这一拍是第 3 级的「留白」。
- 哈希 `f1x0c31`：静止的这一拍结束时，在 COMMIT 下方由一排设备打出来（Mono 光栅，标注级）。

### B.「Pull request, and that is it」（`T.pull` → `T.looks`）
- `T.pull`：飞向 `DIFF` 队形。歌词 `Pull request,`：`pathtext` stand 模式，站在 diff 上一行设备的顶上（歌词级），逐字母。`and that is it`：站在下一行设备顶上。`it`（`T.it`）：diff 的两行里，只有 `<=` 的 `=` 那几台设备熄灭再点成 `<` 的位置不同——**只差一个字符**：其余设备都不动，只有这一个字符的设备飞（这一下要非常干脆：0.12 s）。
- 镜头：从 diff 的左端横移到右端（跟着 `pathtext` 的书写头），`T.it` 时推近到那个字符。

### C.「Then you wrote, “Looks good to me”」（`T.looks` 前后）
- `Then you wrote,`：`pathtext` stand 模式，站在 diff 下方地面（歌词级）。
- `T.looks`：飞向 `CHECK` 队形（大 ✓）；`“Looks good to me”` 用 `WordPlane`（engrave），一块评论牌立在 ✓ 的右边（半屏宽），逐字母点亮；`me”` 长音时评论牌轻轻向镜头倾斜 0.1 rad。

### D.「Merged to main, and now we’re free」（`T.merged` → `T.every`）
- `T.merged`：飞向 `TWO_ROWS`；歌词 `Merged`（6 个字母）每个字母在上一行（分支）的一台设备屏上，`to main,` 的字母在下一行（main）的设备屏上——字母就是屏幕上的字（每台设备一个字母，`WordPlane`）。
- 合并：最终一行是 `Merged to main,` 的 15 个字符位（空格位是一台暗屏设备）。合并前：下一行（main）的 8 台设备已经在第 7–14 位，上一行（分支）的 6 台设备在第 0–5 位的正上方（高 1.2）。从 `to`.start 到 `main,`.end，**光标**（一台 clay 的小设备，拉链头）从左往右走，它经过哪一位，那一位上方的设备就落下插进这一行（`ease.inQuad` 0.15 s，落位时整行震一下），第 6 位的空格设备从下方升起补位。合并后这一行从左到右读出 `Merged to main,`。
- `and now we’re`：`pathtext` stand，站在合并后那一行的上方。
- `free`（`T.free`，长音 1.35 s）：飞向 `SCATTER`——所有设备向四面八方飞起（这里过渡时长用整个 `free` 的长度，`ease.outCubic`），镜头跟着往后退，`free` 的四个字母各在一台飞得最远的设备屏上。

### E.「And it works on every machine」（`T.every` 前后）→ 退场
- `And it works`：设备从 `SCATTER` 飞回 `CLAWD` 队形（时长到 `T.every`），`works` 长音期间 `pathtext` stand 站在设备墙前的地面上。
- `T.every` 起：沿用 v5 现有的最后一段（设备墙正面、远处的 Clawd 群、每块屏上都是 every machine、拉远到 `WALL_BOX`），不改。
- **退场（C17，改定）**：切点前一帧，设备墙正面，所有**亮着的屏幕中心**的投影点 `screenPoints()`（约 70 个点）= S18 第一帧最先亮的星（见 V6-S18）。`exitPrim` = `{ kind: 'points', pts }`（`kit/handoff.ts` 的 `Prim` 由 C 加上 `points` 类型；误差按逐点最大值 ≤ 2 px）。`machine`（131.42–131.95）在 S17 内唱完（尾巴 0.06 s 不跨）。
