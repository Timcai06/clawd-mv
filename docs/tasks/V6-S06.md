# V6-S06：清单——一台绘图仪，和一盏越压越低的灯（17.764 → 20.901 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C5、C6）。设计：C。实现：Codex，严格按本规格。整场重写（v5 方法）。

## 设计意图
上一场最后那条下划线，是这台绘图仪纸面上的第一条格线。笔（clay 光标就是笔尖）把「Read the code,」「write a plan,」按唱的速度一笔一笔写在格线上。纸的上方，巨大的 CHECK 是一块浮雕，被光照着。唱三声 check，笔在三行的方框里各打一个勾；同一瞬间，那盏灯一次比一次压得低，CHECK 的影子一次比一次长、刻线一次比一次密——字的「分量」是光给的。最后笔抬起来，飞到一个点上落下——下一场第一颗被按下的键就在那里。

## 时间
`T.todo` = S06-1（17.764）、`T.checksCut` = S06-2（`check`，19.55）、`T.keyboard` = S07-1（20.901）。第 4 行：`Read`(17.74) `the`(17.98) `code,`(18.16–18.46) `write`(18.66) `a`(18.94) `plan,`(19.04–19.36) `check,`(19.72) `check,`(20.18) `check`(20.62–20.84)。`T.checks` 用 `parts/s06-timing.ts` 现有的取法（实测军鼓）；它必须在 `T.keyboard` 之前，第三个若取不到军鼓就用 `check` 第三次的 start（现在的回退逻辑），测试同步改。

## 1. 数学世界 `parts/s06-world.ts`（y 向上，纸床在 xz 平面 y = 0）
- **纸床**：长方形纸 19.2 × 10.8（世界单位 = 屏幕 px / 100 的量级），paper；纸下是 ink 的台面。
- **格线**：三条横线（行），纸面 z = −1.2、0.2、1.6（离镜头由远到近），x 从 −3.7 到 3.7。第 1 条就是 C5 接进来的那条线（见第 4 节）。每行左端一个方框（0.55 × 0.55，线宽 0.025），第 3 行右边预印 `Fix October`（Plex Mono，字高 0.42，ink 60%——机器文字，平面印刷）。
- **CHECK 浮雕**：`kit/solidtype` 的 `SolidText('CHECK', { axes: { wdth: 100, wght: 900 }, capH: 4.2, depth: 0.25 })`，平躺在纸床远端（字的底边沿 z = −2.6，字面朝 +y），x 居中，左右出画（裁切）。
- **绘图仪**：龙门横梁（长方体 21 × 0.3 × 0.4，架在纸床上方 y = 0.9，沿 z 移动）、笔架（0.5 × 0.5 × 0.6，沿横梁 x 移动）、笔（细圆柱，长 0.8，笔尖是 clay 光标——自发光）。笔有抬起 / 落下（笔尖 y：抬起 0.18，落下 0）。笔尖位置 `penAt(t)` 是本场的核心函数：横梁 z = 笔尖 z，笔架 x = 笔尖 x。
- **光**：一盏方向光，方位角固定（从左前方），**仰角随 check 分三级下降**：开始 62°；第 k 次 check（k = 1,2,3）在 `T.checks[k−1]` 起 0.18 s 内 `ease.outCubic` 降到 42°、24°、11°。投影：CHECK、龙门、笔投到纸上。所有网格用 `engraveMaterial`（纸色底、ink 刻线）。CHECK 的影子会随着光压低一下下拉长，盖住它前面的纸。
- 导出：`penAt(t)`（世界坐标 + 抬落状态）、`checkLight(t)`、`rowLine(k)`。

## 2. 笔怎么动（`penAt`）
1. `T.todo`：笔尖落在第 1 行格线的左端上方（抬起）。
2. 写「Read the code,」：用 `engine/stroke.ts` 的单线字体 `readable`（字高 0.62），基线在第 1 行格线上方 0.08；书写进度用 `writtenLength`，字符时刻用 `letterTimes`（每个字母的笔画在它的 [t0, t1] 内写完）；字与字之间笔抬起。笔尖 = 当前书写点。
3. `code,` 写完 → `write`.start 前：笔抬起移到第 2 行左端（`ease.inOutQuad`）。
4. 写「write a plan,」同上，在第 2 行。
5. 三声 check：第 k 次，笔在 `T.checks[k−1] − 0.12 s` 抬起飞到第 k 行方框，`T.checks[k−1]` 落下画一个勾（两笔折线，0.27 拍，clay 墨水），同一时刻光压低一级（第 1 节）。
6. 第三个勾画完 → `T.keyboard − 1/60`：笔抬起，飞到 C6 的落点，最后 0.1 s 落下（笔尖碰纸）。

## 3. 镜头 `cameraAt(t)`
| 段 | 区间 | 机位 | 缓动 |
|---|---|---|---|
| 接 | `T.todo` | 斜俯视（pitch −1.05，yaw 0.08），使第 1 行格线投影 = `strike05`（C5，误差 ≤ 2 px） | — |
| 写 | → `T.checksCut` | 目标跟着笔尖（目标 = 0.6·笔尖 + 0.4·纸心），距离慢推 −8% | 线性 |
| 勾 | `T.checksCut` → 第三个 check + 0.27 拍 | 拉远到能同时看到 CHECK 和三行；每个 check 冲一下（距离 −2.5%，0.1 s 衰减；震 5 px） | `ease.inOutCubic` 拉远 |
| 俯冲 | 最后 1 拍 | 镜头朝笔尖俯冲、roll 增加到 −0.26（下一场开头的「高处、倾斜」机位由此接上），使笔尖点投影 = `pen06`（671, 809） | `ease.inCubic` |

## 4. 进场（C5）
第一帧：第 1 行格线的投影 = `strike05`（`{x0: 588, x1: 1295, y: 538}`）。格线在第一帧是 clay（刚从上一场的下划线变过来），0.5 拍内冷却成 ink。`entryPrim(t)` = 格线投影 `{kind:'line'}`。

## 5. 歌词
- **Read the code, / write a plan,**：就是笔写出来的单线字（歌词级：投影后字高 50–110 px）。墨水刚写出时是 clay，0.28 s 冷却成 ink。
- **check ×3**：勾 + CHECK 的光。CHECK 不是用来「显示」这个词的标题，它是被光压出分量的实体；三次 check 之后它是画面里最暗、最重的东西。CHECK 浮雕在 `T.todo` 就在（未唱前就存在——它是场景物件，不是唱词；不受「不早于人声」限制，但它的光在第一个 check 前保持最高仰角）。
- 层级：主导元素是 CHECK 浮雕（投影包围盒 ≥ 30% 画面，至少在「勾」段）；标注只有 `Fix October` 一处。

## 6. 退场（C6）
`exitPrim(t)` = 笔尖投影 `{ kind: 'point', x, y, r: 6 }`，`T.keyboard − 1/60` 时 = `pen06`。另外导出 `exitVelocity(t)`（笔尖在屏幕上的速度和镜头 roll 的角速度），S07 接。
