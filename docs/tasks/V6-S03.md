# V6-S03：Issue——一张会被盖章的纸（6.512 → 10.566 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C2、C3）。设计：C。实现：Codex，严格按本规格。

## 设计意图
上一场留下的分割线就是这张纸的左边缘。纸滑进来、在 3D 里躺下，是一张有一点卷曲的真纸，被低角度的光扫着。光标是打字头，把「Got a bug report,」一个字母一个字母打进标题栏；唱到 bug，一枚真的橡皮章从镜头这边砸下来，把纸压出一个凹坑，抬起来留下 clay 的 BUG。唱到 weirdest，笔在附件的月历上圈出 32。最后两拍镜头俯冲进这张月历——它就是下一场整座城。

## 时间
`T.issue` = 6.512、`T.end` = S04-1 起点（10.566）。第 1 行：`Got`(6.72) `a`(7.04) `bug`(7.16–7.68) `report,`(7.68–8.40) `the`(8.67) `weirdest`(9.20) `I’ve`(9.69) `seen`(9.92–10.54)。`screen` 的尾巴（到 6.72）从 S02 带进来。

## 1. 数学世界 `parts/s03-world.ts`
- **纸**：A 规格比例的长方形，宽 `PW = 17.9`、高 `PH = 10.0`（世界单位 = 现在 `FORM` 的 px / 100），躺在桌面 y = 0 上。纸在 xz 平面上，纸面高度 `paperY(x, z, t)`（y 向上） = 卷曲 + 凹坑：
  - 卷曲：`0.10·(1 − cos(π·(x−x0)/PW))·0.5 + 0.18·smoothstep(0.75, 1, u)·smoothstep(0.7, 1, v)`（右上角微微翘起；u、v 是纸面归一化坐标）。
  - 凹坑：`−0.05 · stampMask(x, z) · press(t)`，`press` 见第 3 节；`stampMask` 是章面形状（BUG 字形的外接圆角矩形，边缘 0.15 平滑）。
  - 用位移网格渲染（`PlaneGeometry` 480×270 段，顶点着色器按 `paperY` 抬高，片元按解析法线算光）。CPU 导出同一个 `paperY` 和 `paperNormal`。
- **纸面内容**：现有 `drawForm`（机器文字 ≤ 60% 不透明）画进一张贴图（`SCALE` 倍分辨率），贴在纸上；附件月历（现有 `drawCalendar` 的布局，网格比例 7 × 5）画在纸的右上区域，矩形 `CAL`（纸面坐标，= 现在 `HANDOFF.month03` 的 px / 100）。
- **光**：一盏低角度的主光，方向 `normalize(−0.8, 0.35, −0.3)`（从左上方贴着纸面扫过来，卷曲和凹坑会有清楚的明暗），加 0.18 环境光。纸面：`engraveTone` → ink 刻线（细、密，方向沿纸的 x），亮处几乎无线；印在纸上的墨色乘以 `0.6 + 0.4·光照`（纸上的字也受光）。
- 桌面（纸以外）：ink，带一层极淡的平行刻线（同光照规则），纸在桌面上投下柔和阴影（`kit/raymarch` 的 `softShadow` 不适用于网格——用纸的高度场在片元里朝光方向做 16 步高度场阴影，照 S07 的做法）。

## 3. 歌词
- **「Got a bug report,」**：标题栏两行巨字（现在的版面：第一行 Got a bug、第二行 report,；大写高 315.6 px 是**纸面上**的尺寸，换算成世界 3.156），用 `pathtext` **lie** 模式，路径 = 纸面上的两条基线（随 `paperY` 起伏，normal = `paperNormal`），字是**印上去的**：字母按 `letterTimes` 出现，出现瞬间白热（clay → ink 冷却），并带一个 0.05 s 的打字下压（字母先缩 8% 再回）。书写头 = 光标：一个 clay 光标块立在纸面上（`cursorAt(t)` = `writeHead` 处的纸面点），打字时往右跳，打字的火花用 `sparkParticles`（每个字母 6 粒，纸色背景上用印刷笔触）。
- **bug** 不打字：它是**橡皮章**。章是一个 3D 实体（圆角长方块 + 底面凸起的 BUG 反字，`STAMP = { 纸面中心 (11.9, 7.66), 转角 −0.21, 宽 8.1, 高 3.4 }`）：`bug`.start − 0.12 s 从镜头这边（相机位置附近）落下，`ease.inQuad`，`bug`.start 正好压到纸面（`press` 0 → 1 in 0.03 s，保持 0.14 s，`springStep` 回 0），压下瞬间镜头震 9 px、纸面凹坑出现；章抬起（0.2 s，向镜头外飞走）后，纸上留下 clay 的 BUG（用现有 `stamp()` 的磨损纹理，印进纸面贴图，从这一刻起永久存在并跟着纸面受光）。BUG 印迹是这一镜的主导元素。
- **「the weirdest I’ve seen」**：NOTES 栏（纸面上 `y = 9.72` 那一行）lie 模式，歌词级（纸面上大写高 0.508，投影后要在 50–110 px），同样被光标打出来。
- **weirdest**：笔（光标变成笔尖，clay）在月历 32 格上画一个椭圆圈（现有椭圆参数），用 `kit/stroke` 的书写进度，从 `weirdest`.start 画到 `I’ve`.start；圈是 clay。
- **`screen` 的尾巴（C2）**：第一帧按 S02 的 carry 仿射画；0.12 s 内 `lerpAffines` 到纸面上 NOTES 栏左侧的一个位置（在纸面上以 lie 模式落定），之后跟着纸走。
- 层级：E2 时主导是标题巨字和 BUG 印迹；表格的机器文字 ≤ 60%；同屏标注 ≤ 2（`ISSUE REPORT / FORM 032` 和 `ID / CAL-2026-01032 …`，其余字段文字算纸面内容，不算标注，但都 ≤ 60%）。
