## 设计意图
「Stack traces falling like rain from the sky」现在是一块斜放的平面字。改成：每个字母从风暴深处落下来，沿着雨的斜线掉到一条看不见的「水面」上停住——就像 pdoom 的 drop 沿下落轨迹排字。`falling` 这个词不停，一直掉出画面；`rain` 落地时溅开；`sky`（长音）反过来往上飘。全片唯一一滴 clay 的雨是光标，它落在每个词上。

## 2. 歌词
### 「Stack traces falling like rain from the sky」：下落排字
- 坐标：风暴的世界（相机 roll = `ROLL`，相机沿 z 前进的 `view`）。字放在 z = −7 的一个竖直平面上（雨幕中间），用 `pathtext` **stand** 模式，路径 = 该平面上的两行「水面」（第一行 `Stack traces falling like`，第二行 `rain from the sky`，行首对齐，行距 1.4 capH，capH = 1.0），`up` = 屏幕「上」方向在世界里的向量（随 roll）。
- 每个字母的 `offset(g, t)`：出生时（`t0`）在水面上方 `H0 = 9` 处，沿雨的方向（和风暴的雨丝同一方向）下落，`d(t) = H0 − ½·g·(t−t0)²`（`g` 由「0.45 拍落到水面」反解），落到水面后停住（`springStep` 0.1 s 的小弹）。冷却 paper，`traces` 不重读。
- `falling`：不停在水面上——继续以落到水面时的速度下落，出画后不画。
- `rain`：落到水面瞬间，每个字母碎成 6 道短雨丝（沿雨方向的 LineBatch 线段，长 0.3–0.8 capH，0.25 s 内下落淡出）——字变成了雨。
- `sky`（长音）：字母从水面**向上**飘起（反重力，`d(t) = 0.8·(t−t0)`），一直飘到画面上方出画。
- 光标：一滴 clay 的雨（比雨丝粗 3 倍、长 1.5 capH），每个词的第一个字母出生时它从上方落到该字母位置（每个词一次），`cursorAt(t)` 导出。

### 「Undefined, undefined」：保留现有的两次砸字 + 缺字方框。

### 「and I don’t know why」：站在方框行下面
- 现在是屏幕底部居中的平面字（`drawSet` at y = 1040）。改成：`pathtext` stand 模式（屏幕空间退化：路径是方框行下方 0.9 × 方框高处的一条水平线，用一个正交 `Rig` 或直接把 Canvas 当路径平面；取舍写报告），字从方框行下面「挂」出来：每个字母出生时从方框底边向下伸出（`offset` 的 `scale.y` 0 → 1，0.12 s），像从缺字的框里掉出来的字。`why` clay。
- **why 跨切点（C11）**：`CarrySpec` = 它在这一行里的屏幕位置；S12 开头接手（见 V6-S12）。
