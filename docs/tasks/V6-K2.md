## 设计意图
v5 的规矩是「先算光，再把光照换算成刻线疏密」。光线步进的场景已经有 `engraveTone`；但很多 v6 场景要用普通的 three.js 网格（拉伸出来的字、抽屉、骨牌），并且要真实的阴影贴图。本任务给网格一个同样规矩的材质：用 three.js 自己的光照和阴影算出明暗，最后一步换成刻线覆盖率。再在它上面做「实体字」：每个字母是一块有厚度、有倒角的实体，能单独移动、投影、被照亮。

## 1. `kit/engrave-mat.ts`
```ts
export interface EngraveOpts {
  ink: RGB; paper: RGB;          // 线性 RGB：线的颜色、底的颜色（线 = ink 画在 paper 上；ink 场景里反过来传）
  angle?: number;                // 刻线的屏幕方向（弧度），默认 0.6
  pitch?: number;                // 刻线间距（逻辑 px），默认 5
  faceAngles?: boolean;          // true：按面的朝向（法线在屏幕上的投影）加 ±0.5 rad 偏转，让不同的面线向不同（版画的「随形排线」），默认 true
  gamma?: number;                // 明暗→覆盖率曲线，默认和 engraveTone 一致
  emissive?: RGB; emissiveK?: number;   // 自发光（clay 光标、I），不刻线，直接加
  minCov?: number;               // 最亮处的最小覆盖率，默认 0.02（亮面几乎无线）
}
export function engraveMaterial(o: EngraveOpts): THREE.MeshLambertMaterial   // 用 onBeforeCompile 改写
export function setEngrave(m: THREE.MeshLambertMaterial, o: Partial<EngraveOpts>): void
```
- 做法：`MeshLambertMaterial` + `onBeforeCompile`：保留 three 的光照和阴影（`#include <lights_fragment_end>` 之后），取出 `outgoingLight` 的亮度 `L`（不含 emissive），`tone = clamp(L)`；覆盖率 `cov = 刻线(tone)`：刻线是屏幕空间的平行线（用 `gl_FragCoord` 换成逻辑 px：除以 `PX_SCALE`），线宽随 `1 - tone` 增大，抗锯齿用 `fwidth`，4K 下线的逻辑宽度不变（照 `pxLine` 的写法）；输出 `mix(paper, ink, cov) + emissive`。
- 阴影：材质要支持 `receiveShadow` / `castShadow`（three 的标准阴影贴图）。
- 确定性：同一 t、同一几何，逐像素一致（不读时间，不用随机）。

## 2. `kit/solidtype.ts`
```ts
export interface SolidTextOpts {
  capH: number;                  // 世界单位的大写高
  axes: Axes;                    // Archivo 轴（连续，vartype）
  depth: number;                 // 拉伸厚度（世界单位）
  bevel?: number;                // 倒角（世界单位），默认 depth * 0.1
  tracking?: number;             // em
  material: THREE.Material;      // 通常是 engraveMaterial(...)
  curveSegments?: number;        // 默认 6
}
export class SolidText {
  readonly group: THREE.Group;                    // 整词；字母是它的子节点
  readonly letters: { ch: string; mesh: THREE.Mesh; x: number; adv: number; i: number }[];  // x = 字母左边在词里的位置（世界）
  readonly width: number; readonly capH: number;
  constructor(text: string, o: SolidTextOpts)
  /** 每个字母的局部变换：位置偏移、绕自身中心的旋转、缩放（三轴）。 */
  setLetter(i: number, p: { d?: P3; rot?: P3; scale?: P3; visible?: boolean }): void
  /** 字母的世界包围盒（8 个角点），测试和构图用。 */
  letterCorners(i: number): P3[]
  dispose(): void
}
export function solidLetterGeometry(ch: string, axes: Axes, capH: number, depth: number, bevel: number, curveSegments?: number): THREE.ExtrudeGeometry   // 带缓存
```
- 几何：`varGlyph(ch, axes)` 的轮廓转成 `THREE.ShapePath`（M/L/Q/C/Z → moveTo/lineTo/quadraticCurveTo/bezierCurveTo/closePath；注意字体坐标 y 向下，要翻成 y 向上），`toShapes(true)`（非零环绕，处理字母里的洞：O、A、e……），`ExtrudeGeometry({ depth, bevelEnabled: true, bevelThickness, bevelSize, bevelSegments: 2, curveSegments })`；字母原点：左下基线，正面朝 +z，背面在 z = 0（贴在平面上时背面贴住）。
- 缓存：按 `ch + 轴量化（wdth 0.5、wght 5）+ capH + depth + bevel` 缓存几何；`dispose` 不释放共享缓存（提供 `disposeSolidCache()`）。
- 排版：字距和 kern 用 `varRun` 的结果（大小 100 时换算），保证和 `fillRun` 画出来的 2D 版面完全一致（测试：每个字母的 x 误差 < 0.001 × capH）。
- 性能：建一个 10 字母的词 < 30 ms（首次），复用缓存 < 2 ms；每帧 `setLetter` 只改矩阵。
