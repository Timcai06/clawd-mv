# V6-S18：第二天——机器变成星星，城市迎来十一月（131.894 → 160.6 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C17、C18）、`docs/tasks/V6-S04.md`（日历城）、`docs/tasks/V6-S01.md`（开场）。设计：C。实现：Codex（推理强度 xhigh），严格按本规格。整场重写（v5 方法）。**片尾署名卡（A FILM BY · 作品 / TIM 蔡任天，逐字按八分音符落下，中文用 PingFang SC）必须保留**（Tim 2026-10-01 的要求）。

## 设计意图
尾奏把全片的线收回来。上一场每一块亮着的屏幕，在这一场第一帧变成一颗星。合唱的每一声「oh」点亮一颗新星，星星连成那只 Clawd 的星座。镜头慢慢低下来：地平线上是 S04 那座日历城——但只剩 31 栋楼，32 号已经不在了。Clawd 沿着街走回家，在 31 号楼顶趴下睡着。天亮了：太阳从城后升起，低角度的光把楼的影子扫过整座城；OCTOBER 碑像翻牌一样翻成 NOVEMBER。一个光标在 11 月 1 日的屋顶上亮起来，又一声 ping——Issue #1032。最后镜头升到正上方，城市的楼沉回地面，变回一张平的日历，日历变成署名卡；署名之后一切熄灭，只剩一个光标——就是全片第一帧的那个光标。

## 时间
镜头：S18-1 `T.dark`(131.894) · S18-2 `T.exit0`(133.639) · S18-3 `T.home`(137.132) · S18-4 `T.bye`(140.193) · S18-5 `T.cal`(142.378) · `T.dawn` = `T.cal + 8 拍`（现有） · S18-6 `T.ping`(149.352) · S18-7 `T.credits`(152.830) · 结束 `T.end` = 160.6。尾奏的「oh」：没有逐词数据——用 `audio.events('vocal', …)` 的人声起音（`vonset`）作为「oh」的时刻（现有做法：按拍点亮星），取舍写报告。

## 1. 数学世界 `parts/s18-world.ts`
- **天球**：星是天球上的点（半径 200 的球面，方向向量）。前 ~70 颗星的方向 = 从 S17 最后一帧的相机出发、穿过 `screenPoints()` 每个屏幕点的视线方向（所以在开场镜头下，星的投影 = 那些屏幕点，C17）；之后按「oh」逐颗点亮的星，组成 16×5 的 Clawd 星座（每个像素一颗星，在天球上排成 Clawd，位于城市上方）。星用 `LineBatch` 画成十字小亮点（大小随亮度），刚点亮时白热、0.4 s 冷却成 paper。星座的连线在第 n 颗星点亮时画出它和前一颗的连线（细线，paper 40%）。
- **日历城**：复用 `parts/s04-city-model.ts` 的几何（`DATES`、`dateBlock`、`STREETS`）——**只读 import**，不改 S04 的文件；只画 1–31 号楼（32 号不在）。城市在本场的渲染方式和 S04 相同（实体楼 + 阴影 + 刻线），实现可以复用 S04 的材质或用 `engraveMaterial`（取舍写报告），但楼的位置和尺寸必须和 S04 一致。
- **OCTOBER 碑**：和 V6-S04 的同一块碑（同位置、同尺寸）。`T.cal + 4 拍` 起像翻牌一样绕水平轴翻转 180°（`springStep`，0.6 s），背面是 `NOVEMBER`（`WordPlane` engrave）。
- **光**：两盏，按时间交接：
  - 夜（`T.dark` → `T.dawn`）：一盏冷的高角度弱光（月光，仰角 55°，强度 0.25）——城市是稀疏的刻线，几乎是剪影。
  - 黎明（`T.dawn` → `T.credits`）：太阳是一个 clay 圆盘（发光，地平线后），从地平线下升起（仰角 −4° → 14°，`ease.outCubic`，到 `T.ping`），同时作为方向光（强度 0 → 1），从城市背后照过来：每栋楼的长影子向镜头这边扫过整座城（阴影真实计算，刻线随光变化）。月光同时衰减到 0。
- **Clawd**：体素 Clawd（1 体素 = 0.12），`T.home` 起沿 `STREETS` 走到 31 号楼前、跳上楼顶（`T.bye` 前到位），`T.bye`（歌里「Bye」）挥手（手臂像素抬 2 次），然后趴下（A1 睡姿，闭眼——只有睡觉允许闭眼）；`T.ping` 时睁开一只眼（现有 A2）。
