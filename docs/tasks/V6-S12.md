# V6-S12：重跑——一台复印机，越印越糊（59.424 → 67.227 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C11、C12）。设计：C。实现：Codex，严格按本规格。整场重写（v5 方法）。

## 设计意图
「Run it again」就是复印：每唱一次 run / again，复印机的扫描光条扫过一次，吐出一张新复印件；新复印件是上一张的复印件，所以上面的字一代比一代糊（墨粉噪点变多、对比漂移、轻微放大和歪斜），而这一次新唱的那句是清楚的——歌词本身在重复中退化。「Clear the cache」：一根刮板扫过，所有复印件被扫出画面。「count to ten」：数字一块块立起来，数到 10，再多出一个 clay 的 11（差一错误）。镜头推进 11 的第二笔，它的边就是下一场 clay 和 ink 的分界线。

## 1. 数学世界 `parts/s12-world.ts`（y 向上，桌面 y = 0）
- **桌面**：ink，无限大。
- **复印件**：纸张 `SHEET = 2.1 × 2.97`（A4 比例，世界单位），平躺在桌面上，排成一行（行方向 x），间距 2.4；第 k 张（k = 0…）在第 k 次复印事件时从画面右侧外滑入到它的槽位（`ease.outExpo` 0.35 s），并带一点随机旋转（±0.04 rad，`mulberry32(1200 + k)`）。
- **复印事件** `copies`：`Run`、`again,`、`run`、`again,`、`again` 五个词的 start（按时间排序：60.28、60.66、61.12、61.72、62.36）。
- **纸面内容**（每张一张 Canvas 贴图，每帧按 t 重画，确定性）：第 k 张印的是「到第 k 个事件为止唱过的第 15 行文字」，排成 3 行（`Run it again,` / `run it again,` / `again`），Archivo，纸面上大写高 0.26；**代际退化**：第 k 张上，第 j 个事件（j < k）引入的文字经过了 k − j 次复印：墨粉噪点密度 `0.04·(k−j)`，模糊 `0.6·(k−j)` px（贴图像素），整体放大 `1 + 0.012·(k−j)`、旋转 `0.006·(k−j)`；第 k 个事件刚唱的那一段是清楚的、白热（clay → ink 冷却）。噪点用 `hash(k, j, i)` 固定种子。
- **扫描光条**（光标，R6）：一根横跨纸行的 clay 发光长条（长方体 0.12 × 0.05 × 3.4，`emissive`），每次复印事件从 `t_k − 0.1 s` 到 `t_k + 0.25 s` 沿 −z 扫过最新那张纸的槽位（`ease.inOutQuad`）。它也是一盏光：一盏 `PointLight`（或 3 盏沿光条排开的点光）随它移动，强度 2.2，照亮附近纸面的纹理（纸张带轻微起伏 `0.01·fbm`，被移动的光扫出明暗——刻线）。
- **主光**：一盏方向光从右上方，强度 0.5，投影。所有网格用 `engraveMaterial`（桌面 ink 底 paper 刻线 `lightLines`；纸面用 `paperMap` 选项采样纸面贴图作为底色——这两个选项 C 在 V6-K2 合并后加）。
- **刮板**（Clear）：一根长条（6 × 0.15 × 0.3）从画面左外，`Clear`.start → `cache`.end，沿 +x 扫过整行纸，纸被刮板推着一张张翻起飞出画面右侧（每张纸在刮板碰到它时获得速度，旋转、飞出；按碰撞时刻解析计算，不用模拟）。
- **数字**：`count`.start 起，`kit/solidtype` 的数字 `1` … `10` 依次立起（每个数字一块，竖直站在桌面上，capH 1.6，wght 900，wdth 75），时刻：从 `count`.start 到 `ten`.start 均分 10 个（第 10 个正好在 `ten`.start）；立起 = 从躺倒（绕 x 轴 −90°）转到直立，`ease.outBack` 0.18 s，落地时桌面震一下。数字排成一行，间距 1.25。**`11`**：在 `ten`.start + 0.55·(`ten`.end − `ten`.start) 立起，clay 实色（不刻线）、比其它数字高 15%，立起后闪红一次（`fail` 色，2 帧，伏笔）——差一。

## 3. 歌词
- **Run it again… again**：就是复印件上的字（第 1 节）——最新那张上新唱的字清楚、白热；旧的字一代代退化。投影大写高（复印段，最新那张）50–110 px。
- **Clear the cache**：`pathtext` lie 模式，写在刮板扫过后露出的空桌面上（刮板后沿一条直线），capH 0.5，被刮板「刷」出来（`notBefore` = 刮板经过该点的时刻）。
- **and count to ten**：`and count to`：stand 模式站在数字行前面的桌面上（歌词级）；`ten` = 数字 10 本身（它立起的时刻就是 `ten`.start），长音期间 `10` 这块数字的宽度轴随 `Voice` 变宽（重新取几何：`solidLetterGeometry` 有缓存，按 wdth 量化 0.5 取）。
- **why 的尾巴（C11）**：第一帧按 S11 的 carry 画；`Run`(60.28) 时第一次复印的光条扫过它——它被「复印」进第 0 张复印件（`lerpAffines` 0.25 s 到第 0 张纸面上的一个位置，之后作为纸面内容的一部分，第 1 代）。
- 层级：复印段主导 = 纸行；数段主导 = 数字行；标注一处：`gen 1 → gen 5`（Mono，最新那张纸旁）。
