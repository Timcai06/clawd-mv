# V6-S04：日历城——进场从平面长出来，歌词铺在街上（10.566 → 13.720 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C3、C4）。设计：C。实现：Codex，严格按本规格。
S04 的世界（v5：真实光照、对 32 栋楼求阴影，`parts/s04-city-model.ts`）**保留不动**。本任务只改三件事：进场、歌词载体、退场。

## 设计意图
上一场的镜头俯冲进纸上的月历，这一场第一帧就是同一张月历——但它已经是城市的地面：32 个日期块此刻高度为 0。两拍之内，日期块从地面长出来，镜头倾成斜俯视（像 pdoom loss 的图表变成地形）。光标沿街一格格数日子，「thirty-second」这个词被它一个字母一个字母刷在街面上，像路面标线；「day in」站在 32 号楼脚下；「October」是一排立在城市后面的巨型刻字碑，随长音变宽。最后镜头朝站在 32 号楼上的 Clawd 加速推进，推进在下一场接着走完。

## 时间
`T.start` = S04-1 起点（10.566，`There’s`.start = 10.54 之后 26 ms）、`T.rise` = S04-2 起点（`October`）、`T.end` = S05-1 起点（13.720）。第 2 行：`There’s`(10.54) `a`(10.79) `thirty-second`(10.89–11.90) `day`(11.90) `in`(12.30) `October`(12.54–13.70)。注意 `There’s` 比场景起点早 26 ms：它的第一个字母在第一帧已经出现（不补画）。

## 1. 进场（C3）
- 第一帧：镜头**正俯视**（pitch = −π/2，看向 −y），roll = 0，月份网格（7 列 × 5 行的日期块底面所占的矩形）投影 = `GRID04 = {300, 150, 1320, 870}`（误差 ≤ 2 px）。用 `fov 32` 和高度解出相机。所有日期块高度 = 0（`extrude = 0`），屋顶上的日期数字可见（它们接手 S03 月历上的数字）。
- `T.start` → `T.start + 2 拍`：`extrude` 0 → 1（每块按 `i / 31 · 0.6` 的错位，`ease.outBack(1.3)`，现有写法），镜头从正俯视用 `ease.inOutCubic` 混到现有 `countCam` 的路径（混合系数 0 → 1，2 拍）。删掉现在的 `handoffIn` 二维月历叠层。
- `entryPrim(t)` = 网格四角投影的包围盒（`{kind:'rect'}`）。

## 2. 歌词
- **There’s a**（10.54–10.89）：`pathtext` **lie** 模式，写在第一周那条街（1 日所在行前面的街面）上，路径 = 现有 `STREETS` 的前一段，capH 0.9（世界），书写头 = 光标。
- **thirty-second**（10.89–11.90，长音被拉长到 1 s）：**路面标线**。`pathtext` lie 模式，路径就是光标数日子走的街道路线 `STREETS`（从 1 日到 31 日），capH 1.1，`upper: true`；字母的出现时刻 = `max(letterTimes, notBefore)`，`notBefore(s)` = 光标走到弧长 s 的时刻（`cityState().travel` 的反函数——在 init 里对时间采样建表求逆）。所以字母是被光标「刷」上去的，跟着数数的节奏在街上铺开；连字符「-」照样画。冷却色：clay 白热 → ink（纸色路面上）。遮挡：`visible(p)` = 从相机到 p 的线段不穿过任何日期块的盒子（CPU 上对 32 个盒子做射线-盒求交；楼挡住的字母不画）。There’s a、day in 同样用这个 `visible`。
- **计数**：屏幕上的 odometer 删掉。数到第 n 天时，第 n 块楼的屋顶数字变 clay（现有 accented 逻辑），这就是计数器。溢出到 32 时，32 号楼的屋顶数字 `32` 以 `ease.outBack` 弹出放大 1.6 倍再回 1.2 倍。
- **day in**（11.90–12.54）：`pathtext` **stand** 模式，路径 = 32 号楼前面地上一条短直线（楼脚下，从楼的左前角向右），capH 0.75，冷却成 ink。
- **October**（12.54–13.70，长音）：**刻字碑**。`kit/wordplane.ts` 的 `WordPlane('OCTOBER', { engrave: true, axes: {wdth: 87.5, wght: 900} })`，竖立在城市后方（月份网格最后一行之后 4 个 CELL 处），底边贴地，`capH = 6.5`（世界），正面朝向镜头的水平投影方向；`tone` = 主光方向和碑面法线的 `dot`（和城市用同一盏光）。唱的时候 `karaoke(October, t)` 从左到右点亮（cSung = clay，cDone = ink），碑的水平缩放 = `Voice.form(October, t).axes.wdth / 87.5`（宽度跟着长音拉宽，以左边为锚）。碑在 32 号楼和镜头之间的遮挡由深度测试决定（碑在后面，楼会挡住碑的一部分——这是想要的）。它替代现在屏幕上的 OCTOBER 巨字标题（删掉）。
- 层级：`T.rise` 之后主导元素是 32 号楼 + OCTOBER 碑；歌词投影大写高（There’s a / day in）在 50–110 px；标注只留 32 号楼旁的 `Oct 32 · not in spec` 一处（现有 note 改文字），其余删。

## 3. 光标（R6：计数头）
光标是 clay 光标块，立在街面上，位置 = `streetAt(travel)`（现有）；它就是 thirty-second 的书写头：`cursorAt(t)` 的投影和 `pathtext` 的 `head` 误差 ≤ 1 px（在 thirty-second 唱的期间）。

## 4. 退场（C4）
- 最后 1 拍（`T.end − 1 拍` → `T.end`）：镜头朝 Clawd（站在 32 号楼顶）推进，`ease.inCubic`，使 Clawd 的屏幕像素大小从当时的值（约 6）涨到 **9**，Clawd 的屏幕位置到 `clawd04` 的 (x, y) = (1132, 418)（像素大小 9 时的左上角）。最后 0.1 s 不能静止（这是规则 3 的例外：这里是推进接推进，用规则 4）——推进的速度保持，`exitEnvelope` 只用它的 `gain`。
- `exitPrim(t)` = `{ kind: 'rect', x, y, w: 16·px, h: 5·px }`（Clawd 的投影包围盒）。另外导出 `exitVelocity(t)` = 包围盒中心和尺寸的每秒变化率，给 S05 接。

- thirty-second 的每个字母：出现时刻 ≥ letterTimes 且 ≥ 光标到达时刻；第一个字母的出现时刻 = max(`thirty-second`.start, 光标到达弧长 s0)。
- OCTOBER 碑：`T.rise + 0.5 拍` 时投影包围盒宽 ≥ 画面 45%；唱完后 karaoke = 1。
- C4：`exitPrim(T.end − 1/60)` 和 S05 的 `entryPrim(T.end)` 误差 ≤ 2 px；速度方向误差 ≤ 10°。
- 静帧：10.60、10.95、11.30、11.70、12.10、12.70、13.20、13.70 s；短片 10.0–14.5 s。
