# V6-S01：冷启动——一盏会眨眼的灯（0 → 5.611 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C1）。设计：C。实现：Codex，严格按本规格。

## 设计意图
全片从黑里开始，**光标是唯一的光源**。它每拍眨一次，世界就跟着亮一次、黑一次。欢迎框被光标的火花画出来，Clawd 在框里睡着，它的影子被光标投到框的背板上（影子戏）。唱到「Nine o’clock, a」，字一个个立在地上，被同一盏灯照亮；唱到 ping，光标猛地长高，变成下一场 PING 的 I。

## 时间锚点（全部从数据算，不写死）
`T.start` = S01-1 起点（0.194）、`T.welcome` = S01-2 起点（1.999）、`T.ping` = S02-1 起点（5.611）。歌词：第 0 行 `Nine`(4.13) `o’clock,`(4.56) `a`(5.20)，`ping`(5.56) 属于 S02。`b(t)` = `audio.beatAt(t)`。

## 1. 数学世界 `parts/s01-world.ts`（CPU + GLSL 双写）
单位米，y 向上，欢迎框的平面 z = 0 朝 +z（镜头一侧）。
- **地面** `y = 0`，无限大。
- **欢迎框** `FRAME = { cx: 0, y0: 0.62, w: 9.6, h: 4.79, bar: 0.07, depth: 0.18 }`：四根方截面的空心矩形框（截面半边长 `bar`，沿 z 方向半厚 `depth`），站在地上方 `y0` 处，由两根细腿（0.04 × 0.62，位于 x = ±4.2）撑着。框内 z = −0.16 处一块**背板**（`w × h`，厚 0.02），是 Clawd 影子的幕布。
- **框的显现**：框的四根边按周长参数 `u ∈ [0,1]` 依次被画出（左边自下而上 → 上边 → 下边 → 右边，和现在 `heatTrail` 的四条路径同序），`reveal(t)` 来自现有的 `bootState().frame`。SDF 里未画出的部分直接裁掉（`max(d, 沿周长的裁剪距离)`），背板在框画完后 0.5 拍内从下往上升起（`ease.outCubic`）。
- **Clawd**：16×5 体素（`reference/clawd/clawd.json` 的官方像素，A1 睡姿，眼睛闭——只有睡觉允许闭眼），体素边长 `0.364`，正面轮廓和像素完全一致，身体厚 4 体素、手脚 2 体素（同 `kit/clawd3d.ts` 的比例）；站在框底边上，水平居中，z = 0。在 SDF 里做成按行合并的盒子并集（每行连续的格子合成一个盒子），这样能投下真实的影子。像素按现有 `bootState().pixels` 逐格出现。
- **光标**：clay 自发光的小块 `CUR = { x: 0.0, y: 0.0, z: 1.25, w: 0.18, h: 0.40, d: 0.06 }`，立在框前的地上（Clawd 正前方）。它也是**点光源**，位置在光标中心。
- **光**：只有光标这一盏点光源（加 0.04 的环境光，避免死黑）。辐照度 `E = I(t) · max(0, N·L) / (d² + 0.35) · softShadow`；`I(t) = blink(t) · (1 + 3·flare(t))`。
  - `blink(t)`：每拍开头亮，亮 0.55 拍后关；关的时候不是瞬间变 0，而是磷光衰减 `exp(−Δt/0.09)`；`T.welcome` 之后到画框结束常亮；`T.ping − 1 拍` 起常亮。
  - `flare(t)`：见第 4 节（光标长成 I 时爆亮）。
- **刻线**：地面的刻线是平行于 x 轴的直线（在画面上是向远处收拢的横线），世界间距 0.05；框、背板、Clawd 用 `faceU` 方向的排线；覆盖率 = `engraveTone(E)`（亮处线细、暗处线粗，最暗处是墨底）。颜色：线是 paper 色，底是 ink；Clawd 的亮面是 clay（Clawd 是全片唯一允许 clay 实色的物体，加上光标）。光标自身是 clay 自发光，不刻线。
- CPU 导出：`sdWorld(p)`、`lightAt(p, t)`（给字和测试用）、`frameBox()`、`clawdBox()`、`cursorBox(t)`。

## 3. 歌词：「Nine o’clock, a」立在地上，被灯照亮
- 载体：`kit/pathtext` **stand** 模式。路径是地上一条直线 `z = 2.3`，x 从 −4.6 起向右；`capH = 0.42`，`axes` 来自 `Voice.form`（`o’clock,` 的长音会变宽）。字的书写头 = 光标的火花：每个字母出现时，从光标位置飞出一粒火花落到该字母底部（`sparkParticles`，一字一粒，0.12 s 抛物线）。
- 字的亮度**由灯决定**：`offset().alpha = 0.3 + 0.7 · lightAt(字母底部中点, t)`（光标眨眼时字也跟着暗）。冷却后的颜色是 paper。
- 投影后大写高要在 50–110 px（P2 宽景下），测试。
- **跨切点（C1）**：本句不跨场重排。S01 导出 `line01Affines(): GlyphAffine[]` = 切点前一帧（`T.ping − 1/60`，P3 末的镜头）每个字母的屏幕仿射；S02 原样使用它们画「Nine o’clock, a」，并沿同一条投影基线续排「on my screen」（见 V6-S02）。
- 层级：P2 宽景下，主导元素是欢迎框（≥ 30% 面积），歌词是第二级，标注只有一处：框内的 `pid 1031 · idle`（现有 `drawNote`，P0 时出现，`T.welcome` 前消失）。

## 4. 退场（C1）：光标长成 PING 的 I
- `I_STEM`：由 S02 导出的 `iStemRect()` 给出（V6-S02 第 1 节）。
- 光标在「a」(5.20) 起：0.25 拍压扁（高 ×0.6、宽 ×1.25，`ease.outQuad`），然后 `ease.outExpo` 拉长，到 `T.ping − 1/60` 时，**光标块的投影包围盒 = I_STEM**（误差 ≤ 2 px）。在世界里就是光标块按需要的高宽长大（底边留在地上会穿过框——允许，光标是光，不是实体：长大的光标不参与 SDF 碰撞，只发光）。
- `flare(t)`：同一时段 0 → 1（`ease.inCubic`），世界被照到最亮，Clawd 的影子在背板上变得又黑又硬。
- `exitPrim(t)` = `{ kind: 'rect', ...光标投影包围盒 }`。

## 6. 可测验收（除 V6-common 第 7 节外）
- P2 宽景（`T.welcome + 4 拍`）：框投影包围盒和 `WELCOME_BOX` 误差 ≤ 3%；Clawd 投影包围盒和 `BOOT_CLAWD`（16×5 × 36.4 px，左上 670, 403）误差 ≤ 5%。
- `lightAt` 在 `blink` 关的时段（例如 `T.start + 0.8 拍`）比亮的时段小至少 10 倍；字的 alpha 跟着变。
- C1：`exitPrim(T.ping − 1/60)` 和 S02 的 `entryPrim(T.ping)` 误差 ≤ 2 px。
- `line01Affines()` 在 `T.ping − 1/60` 和 S02 第一帧使用的仿射逐项相等。
- 性能：本场每帧平均 < 25 ms（光线步进超采样按 `SS_TAP` 约定）。
- 静帧：0.6、1.5、2.6、3.3、4.4、5.0、5.45、5.60 s；短片 0–6.6 s。
