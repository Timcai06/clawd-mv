## 设计意图
上一场 CRT 关机留下的那条横线，就是示波器的基线：扫描束从这条线起振。歌词不再是屏幕上的平面字，而是**扫描束写在荧光玻璃上的字**（照 pdoom spacetime 第一乐章）：扫描头扫到哪里，哪里的字母才亮起来；字母像荧光一样留着余辉慢慢变暗。镜头在「waiting for a pass」升起转向时，字跟着玻璃一起倾斜——它们长在玻璃上。

## 2. 歌词：扫描束写在玻璃上
- 载体：`pathtext` **lie** 模式，路径 = 玻璃平面（z = 0）上的一条水平直线：屏幕 y = 427 那一行在世界里的位置（`wy(427)`），从 `wx(96)` 起；`normal` = 玻璃法线 (0, 0, 1)；capH = 0.66（= 投影大写高 66 px，在正面机位下）。
- 字母出现时刻 = `max(letterTimes, notBefore(s))`，`notBefore(s)` = 扫描头（`scopeHead`）在该行的 x 第一次扫过字母左边缘的时刻（扫描头每拍扫一次全宽，`T.waiting` 之后）——字是被扫描束「写」出来的。
- 余辉：字母出现后亮度 `1.0 → 0.55`（`exp(−age/1.6)` 衰减到 0.55 停住），颜色：白热（`C_HOT`）→ paper；扫描头每次扫过已写的字母时，它重新亮回 1.0 再衰减（每拍一次，像示波器重绘）。用 `pathtext` 的 `offset().alpha` 实现。
- **pass**：落在扫描头的停留点（现有设计：pass 停在扫描头旁），clay，`blink` 随拍闪（现有）。它跨切点（C9）：最后半拍从玻璃上的姿态 `lerpAffines` 到 `CarrySpec`（= 它在正面机位下的屏幕位置，但此时镜头已升起——所以 carry 版面取 `T.terminalEnd − 1/60` 那一帧它的实际投影，导出 `passCarry()`）。
- 删掉现在 `s09-terminal.ts` 里屏幕平面的 `fillRun` 歌词循环和 `carry(...)`（上一句整句重画——这是 R2 禁止的）。
- `npm test` / `running 19 tests…` 两行是机器的字（Mono 平面），保留。
