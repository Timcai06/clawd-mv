# V6-S05：读码——源码是一面悬崖，歌词是踏脚石（13.720 → 17.764 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C4、C5）。设计：C。实现：Codex，严格按本规格。整场重写（v5 方法）。

## 设计意图
上一场的推进没有停：镜头继续冲向 Clawd，在它面前刹住。Clawd 站在文件树最上面那只抽屉（`src`）上，掰了掰爪子——「crack」的时候抽屉的面板真的裂开一道。三只抽屉每拍拉出一只，像楼梯一样通向下面 `month.ts` 的源码悬崖：每一行代码是从墙里伸出来的一块石条，石条的正面印着那行代码。唱「and read it all over」时，每个词是一块从墙里推出来的实体字，Clawd 一个词一个词往下跳，光标在它旁边一行行下划正在读的代码。最后一条下划线，就是下一场清单上的第一条线。

## 1. 数学世界 `parts/s05-world.ts`（单位：1 = 100 逻辑 px 量级，y 向上，墙面 z = 0 朝 +z）
- **墙**：平面 z = 0，无限大。
- **源码石条**：`MONTH_SOURCE`（`kit/content.ts`）第 i 行（从 0 数，取第 18–44 行）是一块长方体：`x ∈ [x0 + indent·CW, x0 + (indent + len)·CW]`，`y ∈ [yi − 0.12, yi + 0.12]`，`z ∈ [0, 0.35]`；`CW = 0.14`，`yi = −0.5·(i − 18)`，`x0 = −6`。空行没有石条。正面（z = 0.35）印这行代码（IBM Plex Mono，字高 0.16，`planeAffine`，不透明度 ≤ 60%，paper 色）。
- **抽屉**（文件树）：三只，`DRAWER_k`（k = 0,1,2 对应 src / calendar / month.ts）：盒子 4.4 × 0.9 × 1.2（宽 × 高 × 深），左下前角在 `(−6 + 2.6k, 2.6 − 1.15k, 0)`；拉出量 `out_k(t)` 沿 +z，0 → 1.2，各在 `T.drawers + k 拍` 起 `ease.outExpo` 0.7 拍（现有节奏）。正面印标签（Mono，`src` / `calendar` / `month.ts`，字高 0.28）。
- **裂缝**：`crack`.start 起 0.24 s，src 抽屉正面从 Clawd 爪子位置向右下方传出一道折线裂缝（6 段，随机种子固定 `mulberry32(505)`，总长 2.6），在材质里画成刻进去的凹槽（线两侧一亮一暗，表示有深度）。
- **歌词踏脚石**：「and read it all over」每个词是 `kit/solidtype.ts` 的 `SolidText`（`axes` 来自 `Voice.form` 在该词唱完时的值，`capH = 0.55`，`depth = 0.4`），背面贴墙，排成向右下的台阶：词 j 的左下角 = `(−0.4 + 2.1j, −1.2 − 0.55j, 0)`（j = 0 … 4）。每个字母在它的 `letterTimes.t0` 从墙里推出来：z 方向缩放 0 → 1，`ease.outExpo` 0.12 s；推出前不画。
- **光**：一盏方向光从左上前方 `normalize(−0.5, 0.8, 0.6)`，投影（墙接收石条、抽屉、字、Clawd 的影子），环境光 0.12。所有网格用 `engraveMaterial`：墙是 ink 底，受光处是 paper 色刻线（亮处线多，暗处少——深色底的刻法，用 `lightLines` 选项，C 在 V6-K2 合并后加）；石条和字的受光面刻线同理。光标和 Clawd 例外（clay）。
- CPU 导出：`ledgeBox(i)`、`drawerBox(k, t)`、`wordStone(j)`（世界包围盒）、`clawdAt(t)`、`cursorAt(t)`。

## 2. Clawd 和光标
- Clawd 用 `kit/clawd3d.ts` 的体素 Clawd，1 体素 = 0.16。
  - `T.start` → `T.drawers`：站在 src 抽屉顶面中间。`crack` 时做 A10（掰爪子：两侧手臂像素上下各弹 1 格，0.24 s），同一时刻裂缝出现。
  - `T.drawers` → `T.read`：每只抽屉拉出后，Clawd 跳到下一只抽屉上（抛物线，0.45 拍腾空，落地时压扁 15% 再弹回）。
  - `and`(15.80) 起：Clawd 在每个词的 `start` 起跳，落在该词石头的顶面中间（落地时刻 = 起跳 + 0.4 拍，但不晚于下一个词的 start）；落地的冲击让那块石头整体沿 −y 沉 0.04 再弹回（`springStep`）。
- 光标（R6：读码头）：一条 clay 下划线，长度 = 当前正在读的那行石条的正面宽度，贴在石条正面底边下 0.03 处。从 `read`(16.20) 起，每半拍下移一行（读一行），下划线从左往右划出（0.4 拍，`ease.inOutQuad`），石条被读过后它的代码文字不透明度从 0.45 升到 0.6。读到的最后一行是第 42 行 `for (let d = 0; d <= days; d++)`（在 `T.end` 前一帧划完）。`cursorAt(t)` 导出下划线的世界端点。

## 4. 歌词
- **So I crack my claws**：`pathtext` **stand** 模式，路径 = src 抽屉顶面前沿那条线（Clawd 右边），capH 0.32，字站在抽屉上、被同一盏光照（`offset().alpha = 0.35 + 0.65·max(0, dot(上方向, 光方向))` 这类简单受光即可，取舍写进报告）。`crack`：字母出现时整行抖一下（每个字母 y 方向 ±0.03 的确定性抖动，0.12 s 衰减）。`claws` 冷却成 clay（重读词）。抽屉拉出时这行字跟着 src 抽屉一起往 +z 走（它站在抽屉上）。
- **and read it all over**：就是第 1 节的踏脚石（实体字）。字面受光刻线；新推出的字母白热（材质 `emissive` 用 C_HOT 乘 `exp(−age/0.28)`）。`read` 是重读：它那块石头是 clay 实色（不刻线）。
- 层级：A′ 段主导是 Clawd + src 抽屉；C 段主导是踏脚石台阶。标注最多两处：抽屉标签算物体上的字，不算标注；另加一处 `month.ts · 48 lines` 在 B 段出现、C 段消失。
