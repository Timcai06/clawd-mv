# V6-S10：玻璃墙——字刻在玻璃上，和玻璃一起碎（48.693 → 52.269 s）

先读 `docs/tasks/V6-common.md`、`docs/tasks/V6-cuts.md`（C9、C10）。设计：C。实现：Codex，严格按本规格。
S10 的世界（v5：19 块玻璃板实体碎裂，`parts/s10-world.ts`）**保留不动**。本任务改歌词和进场。

## 设计意图
歌词条已经在世界里（印在整排玻璃的面上，碎的时候每块碎片带走自己那一截字）——方向对，但 v5 实测里它太小，读不出来，而且上一句被整句重画在屏幕上。改法：这一句刻在玻璃上，**歌词级**大小，**逐字母**被盖章的光标刻上去；上一场跨过来的 pass 被第一块玻璃从前面滑过盖住。

## 时间
`T.wallStart` = S10-1（48.693）、`T.shatter` = S10-2（`shattering`）、`T.rainStart` = S11-1（52.269）。第 12 行：`Nineteen`(49.36–50.26) `red,`(50.26) `and`(50.72) `they’re`(50.80) `shattering`(50.92–51.60) `like`(51.60) `glass`(51.95–52.54，跨切点 0.27 s)。

## 1. 进场（C9）
- 19：`nineteen09`（现有），`entryPrim` 测试化。
- `pass` 的 carry：第一帧按 S09 的 `passCarry()` 画；0.2 s 内第一块玻璃板沿行方向从画面左侧滑入，从 pass 前面经过——pass 被玻璃盖住后亮度降到 0.35（透过玻璃看），`pass`.end（49.12）起 0.12 s 内淡出（被玻璃挡住看不见了——这是「被世界处理掉」，允许淡出）。
- 删掉 `s10-redwall.ts` 里的 `carry(c, v, t, T.wallStart, 96, 348, 'paper')`（R2 禁止的整句重画）。

## 2. 歌词：刻在玻璃上
- 载体保留现有的「歌词条」（`strip` 贴图，在着色器里按整排玻璃的静止世界坐标印在面上，碎片带走自己那一截）。改三处：
  1. **尺寸**：字条在玻璃上的大写高改成 0.62 世界单位，使在 `T.wallStart + 1 拍` 的镜头下投影大写高 60–90 px；字条位置在玻璃面的 v = 0.30–0.42（报告文字的上方，不重叠）。
  2. **逐字母**：字条贴图里每个字母在 `max(letterTimes, 盖章到达时刻)` 才画上去（盖章到达 = 盖 X 的光标走到这个字母所在的那块玻璃的时刻，`plateStampTime(i)` 现有）；出现时白热（`C_HOT`）→ paper 冷却 0.28 s。
  3. **重读**：`shattering` 的字母是 clay。
- `Nineteen`：保留现有的 odometer 计数 19（机器计数器，屏幕平面，Mono 例外允许），但它的大小改成标注级之上的歌词级（大写高 70 px），不再 196 px（主导元素是玻璃墙，不是计数器）。

## 3. 光标（R6）
盖 X 的章头就是光标：一个 clay 光标块，沿整排玻璃逐块跳（每块盖 X 的时刻落在该玻璃板面前），`cursorAt(t)` 导出。

## 4. 退场（C10）
- 运动交接（现有 `fall10`）保留并测试化：切点前一帧所有碎片的屏幕速度方向 = 雨的方向（roll −0.2），平均速率 = 220 px / 拍（误差 ≤ 10%）。
- `glass`：它刻在最后几块玻璃上，随碎片落下；S11 接手这些碎片的继续下落（见 V6-S11）。导出 `glassShards(t)`：带 `glass` 字母的那几块碎片的屏幕位置和字母仿射。
